# Studio Elegancy

Protótipo web de gestão de estúdio de beleza (HTML, CSS, JavaScript e `localStorage`).

Não há backend, API, banco de dados nem autenticação real.

Slogan: **Beleza que te representa.**

## Como executar

Na raiz deste repositório:

```bash
npx --yes serve .
```

Abra o endereço que o comando mostrar.
