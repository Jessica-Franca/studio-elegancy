# Studio Elegancy

O diretório raiz deste workspace é o repositório oficial `Jessica-Franca/studio-elegancy`.

O aplicativo web é a raiz do repositório (`index.html`, `css/`, `js/`).

Não criar clones, cópias ou pastas alternativas do aplicativo.

Não trabalhar em diretórios temporários.

Não utilizar projetos legados como fonte de implementação.

Todo novo desenvolvimento deve ocorrer neste workspace.

Antes de alterações importantes, verificar o Git root e `git status`.

O protótipo usa HTML, CSS, JavaScript e `localStorage`. Não introduzir backend, API, banco de dados ou autenticação real sem pedido explícito.

Não publicar dados reais de clientes, `DocsCliente/`, credenciais ou arquivos da máquina.
